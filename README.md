# Health Care Analysis

##  Project Overview
The Health Care Analysis project focuses on analyzing healthcare data to identify trends, generate insights, and present the results through interactive visualizations. The goal is to make healthcare data easier to understand for better decision-making.

---

## Objectives
- analyze healthcare-related datasets.
- Perform data cleaning and preprocessing.
- Explore trends using statistical analysis.
- Create interactive visualizations.
- Build an easy-to-use dashboard for data exploration.

---

## Technologies Used
- VS code
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit

---

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Interactive Charts and Graphs
- Dashboard with Streamlit
- Key Insights and Trends

## Installation

1. Clone the repository

git clone https://github.com/sahanadevira/health-care-analysis-.git
2. Navigate to the project folder

cd health-care-analysis-
3. Install the required libraries

pip install -r requirements.txt
4. Run the Streamlit application

streamlit run app.py
